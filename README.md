# Диалог

Учебное приложение Android: обратная связь, тест и уведомление студента.

Студент: Демаков Дмитрий Максимович, группа Т-433901-НТ.

Откройте папку проекта в Android Studio, дождитесь синхронизации Gradle и запустите приложение на эмуляторе или телефоне. Для уведомлений на Android 13 и новее нужно предоставить разрешение. Кнопка создаёт локальное системное уведомление.
